# ProBG Blog 1.2.0

## Български

Версия 1.2.0 добавя lightbox преглед за допълнителните изображения в галерията на всяка статия.

### Ново

- Клик върху изображение от галерията го отваря върху fullscreen overlay, подобно на Fancybox.
- Добавена е навигация към предишно и следващо изображение.
- Добавен е брояч на текущото изображение спрямо общия брой.
- Поддържат се клавиатурни команди от Magnific Popup: `Esc` за затваряне и стрелки за навигация.
- Клик върху текущото изображение може да премине към следващото изображение.
- Добавен е zoom индикатор върху thumbnail изображенията.
- Lightbox изгледът е оптимизиран за desktop и mobile.
- Ако JavaScript lightbox компонентът не може да се зареди, линковете към оригиналните изображения остават работещи като стандартни линкове.

### Реализация

Използва се Magnific Popup, който е включен стандартно в OpenCart 3. Не се добавя външен CDN или допълнителна third-party инсталация.

Зареждат се:

- `catalog/view/javascript/jquery/magnific/magnific-popup.css`
- `catalog/view/javascript/jquery/magnific/jquery.magnific-popup.min.js`
- `catalog/view/theme/default/stylesheet/probg_blog_lightbox.css`

Lightbox ресурсите се зареждат само при article controller-а.

### След обновяване

Изпълнете **Extensions → Modifications → Refresh** и изчистете theme/cache при нужда.

---

## English

Version 1.2.0 adds a lightbox viewer for additional article gallery images.

### New

- Clicking a gallery image opens it in a fullscreen overlay similar to Fancybox.
- Previous/next image navigation.
- Current/total image counter.
- Keyboard navigation provided by Magnific Popup: `Esc` to close and arrow keys to navigate.
- Clicking the current image can navigate to the next image.
- Added a zoom indicator over gallery thumbnails.
- Responsive desktop and mobile lightbox presentation.
- If the JavaScript lightbox component is unavailable, the original image links still work as normal links.

### Implementation

The feature uses Magnific Popup bundled with OpenCart 3. No external CDN or additional third-party installation is required.

Loaded assets:

- `catalog/view/javascript/jquery/magnific/magnific-popup.css`
- `catalog/view/javascript/jquery/magnific/jquery.magnific-popup.min.js`
- `catalog/view/theme/default/stylesheet/probg_blog_lightbox.css`

Lightbox assets are loaded only on article pages.

### After upgrading

Run **Extensions → Modifications → Refresh** and clear theme/cache if necessary.
