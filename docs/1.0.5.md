# ProBG Blog 1.0.5

## Български

Версия 1.0.5 коригира frontend Notice `Undefined index: route` при преглед на блог статия.

Причината беше в OCMOD SEO rewrite логиката. При обработка на ключа `route` ProBG Blog генерираше SEO сегмента и веднага изпълняваше `unset($data['route'])`. Стандартният OpenCart `catalog/controller/startup/seo_url.php` обаче продължава да използва `$data['route']` в същата итерация, което водеше до Notice.

Корекцията:

- запазва `$data['route']` до края на стандартната OpenCart rewrite обработка;
- премахва само `probg_blog_category_id` и `probg_blog_article_id` след успешно SEO преобразуване;
- добавя `isset($data['route'])` защита;
- запазва йерархичната URL структура `/blog/category/article`.

След обновяване изпълнете **Extensions → Modifications → Refresh**.

## English

Version 1.0.5 fixes the storefront `Undefined index: route` Notice while viewing blog articles.

The issue was caused by the OCMOD SEO rewrite logic. While processing the `route` key, ProBG Blog generated the SEO segment and immediately called `unset($data['route'])`. OpenCart's standard `catalog/controller/startup/seo_url.php` still references `$data['route']` during the same loop iteration, producing the Notice.

The fix:

- keeps `$data['route']` available until standard OpenCart rewrite processing finishes;
- removes only `probg_blog_category_id` and `probg_blog_article_id` after successful SEO conversion;
- adds an `isset($data['route'])` guard;
- preserves the hierarchical `/blog/category/article` URL structure.

After upgrading, run **Extensions → Modifications → Refresh**.
