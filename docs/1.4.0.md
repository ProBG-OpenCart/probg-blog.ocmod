# ProBG Blog 1.4.0

## Български

Версия **1.4.0** преработва административния интерфейс на таб **Меню**, без да променя начина, по който отделните OpenCart module instances се записват и използват във frontend.

### Нов master/detail интерфейс

Вместо всички менюта да се показват едновременно като дълги формуляри, таб **Меню** вече показва компактен списък с всички създадени менюта. За всяко меню се виждат:

- административно име;
- статус;
- активни секции: Blog link, категории и статии;
- избрана категория за статиите;
- режим **Списък / Слайдър**;
- лимит на статиите;
- бутони **Редакция** и **Премахване**.

### Редакция

Бутонът **Редакция** отваря само избраното меню. Останалите менюта са скрити, което прави работата с голям брой menu instances значително по-удобна. Бутон **Към списъка** връща към master списъка.

### Добавяне и премахване

**Добави меню** създава нов menu instance editor и го отваря директно. Премахването може да се извърши както от списъка, така и от editor-а. Както и досега, промените се записват с основния бутон **Запази**.

### Допълнителни UX подобрения

- търсене по име, категория, режим и съдържание;
- визуални status/content badges;
- автоматично отваряне на менюто, което съдържа validation error;
- responsive таблица и mobile-friendly controls;
- няма промяна в съществуващите menu instance данни или Layout assignments.

## English

Version **1.4.0** replaces the expanded-all-at-once Menu tab with a master/detail menu manager. The tab shows a compact searchable table of all menu instances, including status, enabled content sections, selected category, List/Slider display mode and article limit. **Edit** opens only the selected menu, **Back to list** returns to the overview, and **Add menu** opens a fresh editor immediately. Existing OpenCart module instance data and Layout assignments are preserved.
