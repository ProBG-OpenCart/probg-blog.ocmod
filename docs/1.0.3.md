# ProBG Blog 1.0.3

## Български

OpenCart 3 нормализира административните routes `extension/probg_blog/category` и `extension/probg_blog/article` до `extension/probg_blog` при startup access проверката. Версия 1.0.2 добавяше права за child routes, но липсваше родителското `extension/probg_blog`, което водеше до **„Разрешението е отказано“** преди зареждането на controller-а.

Версия 1.0.3 добавя `access` и `modify` за `extension/probg_blog`, като запазва отделните CRUD permissions. След обновяване отворете **ProBG Blog → Настройки** веднъж и изпълнете **Extensions → Modifications → Refresh**.

## English

OpenCart 3 normalizes the administration routes `extension/probg_blog/category` and `extension/probg_blog/article` to `extension/probg_blog` during the startup access check. Version 1.0.2 granted the child routes but missed the parent `extension/probg_blog` permission, causing **Permission Denied** before the controller was loaded.

Version 1.0.3 grants `access` and `modify` for `extension/probg_blog` while preserving the dedicated CRUD permissions. After upgrading, open **ProBG Blog → Settings** once and run **Extensions → Modifications → Refresh**.
