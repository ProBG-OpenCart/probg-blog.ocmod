# ProBG Blog 1.2.1

## Български

Коригира критично рекурсивно зареждане при поставяне на ProBG Blog в **Design → Layouts**, включително на началната страница. Симптомът е PHP `Allowed memory size exhausted`.

Причината е, че OpenCart 3 може да извика single-instance module без `$setting`, а старият source controller стартираше пълния `listing()` renderer. Версия 1.2.1 премества layout/full-page detection директно в catalog controller source и добавя static request-level recursion guard.

След обновяване изпълнете **Extensions → Modifications → Refresh** и изчистете theme/cache.

## English

Fixes critical recursive rendering when ProBG Blog is assigned through **Design → Layouts**, including the home page. The symptom is PHP `Allowed memory size exhausted`. Layout/full-page detection now lives directly in the catalog controller source and uses a static request-level recursion guard.
