# ProBG Blog 1.4.1

## Български

Версия 1.4.1 коригира дублиране на frontend блока, когато ново ProBG Blog menu instance е добавено в Layout, а е останал legacy запис `probg_blog`. След migration към `probg_blog.<module_id>` bare layout извикването вече връща празен резултат. Директните blog страници и валидните instances не се променят.

## English

Version 1.4.1 fixes duplicate storefront blocks caused by a leftover bare `probg_blog` layout entry alongside a migrated `probg_blog.<module_id>` instance. Once migration is complete, the legacy fallback is disabled.
