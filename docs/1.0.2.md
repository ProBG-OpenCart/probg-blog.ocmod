# ProBG Blog 1.0.2

## Български

### Поправки

- Коригиран е проблемът **„Разрешението е отказано“** при отваряне на табовете **Категории** и **Статии** след обновяване на вече инсталиран модул.
- При отваряне на **ProBG Blog → Настройки** потребителска група, която вече има `modify` право за `extension/module/probg_blog`, автоматично получава `access` и `modify` права за:
  - `extension/probg_blog/category`
  - `extension/probg_blog/article`
- Това не дава права на групи, които нямат право да променят основния ProBG Blog модул.
- Административният обзор за **Категории** и **Статии** е коригиран за теми, при които OpenCart dashboard `.tile` стиловете показват бял текст и икони върху бял фон.
- Добавен е отделен stylesheet `view/stylesheet/probg_blog.css`, който се зарежда само на страницата с настройки на ProBG Blog.
- Версията на модула и OCMOD е обновена до `1.0.2`.

### Обновяване от 1.0.1

1. Качете новата версия.
2. Отворете **Extensions → Modifications** и натиснете **Refresh**.
3. Отворете **ProBG Blog → Настройки** веднъж с администратор, който има право да променя модула.
4. След това табовете **Категории** и **Статии** трябва да са достъпни.

## English

### Fixes

- Fixed **Permission Denied** when opening the integrated **Categories** and **Articles** tabs after upgrading an existing installation.
- When **ProBG Blog → Settings** is opened, a user group that already has `modify` permission for `extension/module/probg_blog` automatically receives `access` and `modify` permissions for:
  - `extension/probg_blog/category`
  - `extension/probg_blog/article`
- Groups without permission to modify the main ProBG Blog module are not granted additional rights.
- Fixed the **Categories / Articles** administration overview for admin themes where OpenCart dashboard `.tile` styles render white text and icons on a white background.
- Added a dedicated `view/stylesheet/probg_blog.css` stylesheet loaded only on the ProBG Blog settings page.
- Updated the module and OCMOD version to `1.0.2`.

### Upgrade from 1.0.1

1. Upload the new version.
2. Open **Extensions → Modifications** and click **Refresh**.
3. Open **ProBG Blog → Settings** once with an administrator allowed to modify the module.
4. The **Categories** and **Articles** tabs should then be accessible.
