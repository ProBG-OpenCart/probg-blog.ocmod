# ProBG Blog 1.1.0

## Български

Версия **1.1.0** обновява изцяло storefront представянето на ProBG Blog и коригира breadcrumb навигацията при преглед на статия.

### Корекция на breadcrumb

При статия controller-ът подаваше категорията с ключ `title`, а breadcrumb renderer-ът очаква `text`. В резултат между **Блог** и заглавието на статията се показваше празен breadcrumb елемент.

Версия 1.1.0 добавя `text` към category breadcrumb data и Twig fallback, който използва `category.title`, когато се срещне стар кеширан breadcrumb запис. След обновяване пътят е:

`Начало → Блог → Категория → Статия`

### Bootstrap 5 storefront

Преработени са:

- основната блог страница;
- страница на категория;
- страница на статия;
- блокът с последни статии в Layouts;
- вграденото блог меню;
- галерията на статия;
- свързаните продукти.

Използвани са Bootstrap 5 компоненти и структура:

- `card`;
- `card-body` / `card-header`;
- `breadcrumb` / `breadcrumb-item`;
- `badge`;
- `list-group`;
- responsive grid;
- responsive images;
- Bootstrap utility класове за spacing, flex и typography.

Добавен е `catalog/view/theme/default/stylesheet/probg_blog.css`. Стиловете са scoped към ProBG Blog и съдържат fallback за основните Bootstrap 5 компоненти, така че модулът да остане визуално подреден и върху OpenCart 3 теми, които все още използват Bootstrap 3.

### След обновяване

Изпълнете **Extensions → Modifications → Refresh** и изчистете theme/cache при нужда.

## English

Version **1.1.0** fully refreshes the ProBG Blog storefront presentation and fixes article breadcrumb navigation.

### Breadcrumb fix

The article controller exposed the category using the `title` key while the shared breadcrumb renderer expected `text`. This produced an empty breadcrumb item between **Blog** and the article title.

Version 1.1.0 adds `text` to the category breadcrumb data and keeps a Twig fallback that uses `category.title` for stale cached modification data. The resulting path is:

`Home → Blog → Category → Article`

### Bootstrap 5 storefront

The following templates were redesigned:

- main blog page;
- category page;
- article page;
- latest articles layout block;
- built-in blog menu;
- article gallery;
- related products.

The templates now use Bootstrap 5 component structure including cards, breadcrumb items, badges, list groups, responsive grids, responsive images and utility classes.

A scoped stylesheet is added at `catalog/view/theme/default/stylesheet/probg_blog.css`. It also includes fallbacks for the required Bootstrap 5 components so the module remains visually consistent on OpenCart 3 themes that still ship Bootstrap 3.

### After updating

Run **Extensions → Modifications → Refresh** and clear theme/cache if required.
