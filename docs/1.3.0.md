# ProBG Blog 1.3.0

## Български

Версия 1.3.0 преработва frontend менюто като система от стандартни OpenCart module instances.

### Неограничен брой менюта

В **ProBG Blog → Настройки → Меню** може да се създава неограничен брой менюта. Всяко меню има собствено административно име и се появява като отделна позиция в **Design → Layouts**, например `Blog Sidebar`, `Начална страница — статии`, `Footer Blog`.

### Настройки на всяко меню

- многоезично заглавие;
- статус;
- покажи линк към блога;
- покажи категории;
- покажи статии;
- категория за статиите;
- лимит;
- подредба по дата или sort_order;
- изглед **Списък** или **Слайдър**.

### Slider

Slider режимът е собствен lightweight компонент без външен CDN. Поддържа responsive multi-item изглед, автоматична адаптация за tablet/mobile, prev/next бутони, dots, autoplay, configurable interval, touch swipe и `prefers-reduced-motion`.

### Миграция

При upgrade старата единична menu конфигурация се копира в първото menu instance. Ако старият глобален модул е бил поставен в Layout с output `menu`, записът `probg_blog` се пренасочва към `probg_blog.<module_id>`. Данните на категории и статии не се променят.

## English

Version 1.3.0 converts the frontend menu into standard OpenCart module instances. The Menu tab can create unlimited independent menus, each selectable separately in Design → Layouts. Every menu has its own multilingual title, visibility options, category filter, limit, sorting and List/Slider article display. Legacy menu settings are migrated automatically.
