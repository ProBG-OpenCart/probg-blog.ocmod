# ProBG Blog 1.0.4

## Български

Версия 1.0.4 коригира фаталната SQL грешка `Unknown column 'module' in 'WHERE'`, която възникваше при migration cleanup-а на старите layout модули.

Стандартната OpenCart 3 таблица `layout_module` използва колоната `code`, а не `module`. Cleanup логиката вече проверява схемата чрез `SHOW COLUMNS`, използва `code` при стандартен OpenCart 3 и запазва безопасен fallback за forks.

Премахнат е и грешният early return за вътрешна версия `1.0.1`. Migration-ът вече може безопасно да се изпълни повторно след прекъснат upgrade. Вътрешната model версия е синхронизирана с `1.0.4`.

След обновяване отворете **ProBG Blog → Настройки**. Ако използвате OCMOD кеш, изпълнете и **Extensions → Modifications → Refresh**.

## English

Version 1.0.4 fixes the fatal SQL error `Unknown column 'module' in 'WHERE'` during legacy layout-module migration cleanup.

Standard OpenCart 3 stores layout module identifiers in the `layout_module.code` column, not `module`. Cleanup now detects the schema with `SHOW COLUMNS`, uses `code` on standard OpenCart 3, and retains a safe fallback for forks.

The incorrect early return for internal version `1.0.1` has also been removed. Migrations can now safely rerun after an interrupted upgrade, and the internal model version is synchronized with `1.0.4`.

After upgrading, open **ProBG Blog → Settings**. If OCMOD cache is used, also run **Extensions → Modifications → Refresh**.
