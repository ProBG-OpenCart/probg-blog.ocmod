# ProBG Blog 1.6.0

## Български

Версия **1.6.0** разширява управлението на основните списъци със статии.

### Нови настройки

- **Статии на страница** — default стойност `12` при нова инсталация. При upgrade съществуващата стойност се запазва.
- **Изглед на списъка със статии** — `Грид` или `Списък`.
- **Покажи описание на категориите в навигацията** — включва/изключва описанията в картите на категориите на основната блог страница.
- **Символи от описанието на категория** — от `1` до `1000`, default `160`.

### Frontend

Grid режимът използва responsive 3/2/1 колони (desktop/tablet/mobile). List режимът показва хоризонтални cards и автоматично преминава към вертикален card на телефон.

Описанието на категорията в навигацията се декодира, HTML таговете се премахват и whitespace се нормализира преди прилагане на лимита. Това предотвратява невалиден HTML при съкращаване.

## English

Version **1.6.0** adds configurable Grid/List archive presentation, a 12-article default for new installations, and category-navigation description controls. Grid uses responsive 3/2/1 columns, while List uses horizontal cards that stack on mobile. Category descriptions are converted to plain text before character truncation.
